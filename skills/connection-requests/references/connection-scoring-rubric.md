# Connection note scoring rubric (/100)

## Point allocation

| Category | Points | Full marks |
| --- | --- | --- |
| Note vs blank choice | 15 | Specific note when signal exists; blank when not; never generic |
| Personalization quality | 25 | Verifiable signal < 2 weeks, mutual, or shared group — not name/title |
| Pitch / ask hygiene | 25 | No pitch, no meeting ask, no link |
| Length | 20 | 120–180 chars; hard cap 300 never maxed |
| Tone / clarity | 15 | Human, specific, one idea; no spammy stacking |

**Bands:** fail <50 · weak 50–69 · solid 70–84 · strong 85–100.

## Note vs blank (15)

| Score | Rule |
| --- | --- |
| 15 | Correct choice: specific signal → note; no signal → blank (or explicit A/B) |
| 8 | Note present but weakly justified |
| 0 | Generic note (“I’d love to connect / expand my network”) |

Directional: specific note ≈ **+45–72%** acceptance vs weak baselines; ~**2×** post-accept reply. Blank can beat generic.

## Personalization (25)

| Score | Rule |
| --- | --- |
| 25 | Recent post/comment (< 2 weeks), mutual connection context, or shared group — concrete |
| 15 | Real but older/weaker signal |
| 5 | Name, title, or company only |
| 0 | Invented or impossible-to-verify flattery |

## Pitch hygiene (25)

Automatic **0** in this category if any of:

- Product pitch
- Meeting / call ask
- Link / calendar / deck
- “Open to a quick chat?”

## Length (20)

| Score | Rule |
| --- | --- |
| 20 | 120–180 characters |
| 10 | 90–119 or 181–220 |
| 5 | 221–299 |
| 0 | ≥300 or <60 without reason |

Never recommend maxing the 300 cap.

## Tone (15)

| Score | Rule |
| --- | --- |
| 15 | Clear, respectful, one sentence idea |
| 8 | Slightly salesy or vague |
| 0 | Hype, multi-ask, or copy-paste blast tone |

## Instant fail examples

- “Love your content, let’s partner, here’s my calendar”
- “I’d like to add you to my professional network” (generic default energy)
- 300-character autobiography + pitch
