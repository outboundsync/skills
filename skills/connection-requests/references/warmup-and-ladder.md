# Warmup and post-accept ladder

## Profile prerequisite (before inviting)

Headline must state **problem + audience**, not job title alone.

| Weak | Stronger |
| --- | --- |
| AE at {{company}} | Help {{audience}} fix {{problem}} |
| Growth | Outbound reply systems for {{audience}} |

If headline is title-only, Findings → · profile prerequisite unmet.

## Warmup (3–4 touches before request)

Light, public, non-creepy touches over several days:

1. View / attend to their content footprint
2. Like or meaningfully react to a recent post
3. Leave a short, substantive comment (adds insight; not “great post!”)
4. Optional: engage a second piece or shared-group thread

Then send the connection request (with specific note or blank).

Do not warmup-spam. Do not automate engagement.

## Invite note rules (recap)

- Specific signal only
- 120–180 chars
- No pitch / meeting / link

## Post-accept ladder

| Step | Timing | Action |
| --- | --- | --- |
| 1 | Immediately after accept | **Nothing** salesy |
| 2 | Wait **~24h** | Open with **one easy question** (opinion / priority), no deck |
| 3 | After reply | Helpful resource or insight |
| 4 | Later | Soft interest CTA — still not a hard demo shove |

**Never** immediate pitch on accept.

### Easy question examples

- `When reply rates stall, do you usually fix copy first or list quality?`
- `Is outbound volume or conversion the tighter constraint this quarter?`

### Banned first DMs

- Calendar link
- Case-study PDF dump
- “Got 15 minutes?”
- Multi-paragraph pitch

## Testing note vs blank

Run as a true A/B when volume allows:

- Cohort A: specific notes only
- Cohort B: blank
- Never use generic notes as a “control” worth keeping

Primary metric: **acceptance rate**, then **post-accept reply rate**.
