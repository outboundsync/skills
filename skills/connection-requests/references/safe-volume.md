# Safe volume and health metrics

Platform-agnostic guidance for professional social outreach invites.

## Safe volume bands

| Account age / trust | Daily invites | Weekly invites |
| --- | --- | --- |
| New / warming | **10–20 / day** | ramp toward 100 |
| Established, healthy | ~**20 / day** | ~**100 / week** |

Stay under these ceilings unless the user has durable historical acceptance and low restriction history. When unsure, ramp slowly.

## Health thresholds

| Metric | Healthy | Caution | Red flag |
| --- | --- | --- | --- |
| Acceptance rate | **> 40%** | 20–40% | **< 20%** |
| Pending invites | **< ~500** | 500–800 | > 800 — withdraw stale |
| Restrictions / warnings | none | recent warning | active limit |

Actions on red flag: pause new invites, withdraw stale pendings, improve targeting/seniority mix, fix generic notes, resume at new-account ramp.

## Seniority benchmarks (acceptance)

| Seniority | Typical acceptance band |
| --- | --- |
| IC / individual contributor | **40–55%** |
| Manager | mid band (often ~30–45%) |
| C-level / VP | **18–25%** |

Judge performance relative to the mix you invite. A C-level-heavy list at 22% can be healthy; an IC list at 22% is not.

## Targeting quality > volume

- Fewer, warmer, signal-based invites beat spray volume
- Shared group / mutual / recent content engagement before ask
- Withdraw invites pending too long (stale)

## Volume check output fields

Always report:

- Current daily / weekly vs safe band
- Acceptance % vs seniority benchmark
- Pending count vs ~500
- Whether to ramp, hold, or pause + withdraw
