# Subject line examples

Neutral placeholders. No named people, companies as gurus, or trademarked frameworks.

## Kill → rewrite

| Before | Issues | After |
| --- | --- | --- |
| `🚀 EXCLUSIVE OFFER!!!` | emoji, CAPS, spam, !!! | `outbound reply rate` |
| `Re: quick question` | fake Re: | `quick question` |
| `{{first_name}}, partnership opportunity` | soft spam, weak token | `{{company}} sdr hiring` |
| `Increase sales with our solution` | spam pair | `pipeline reply lag` |
| `` *(empty)* | empty | `crm sync gap` |

## Strong patterns

| Subject | Why it works |
| --- | --- |
| `reply lag` | 2 words, lowercase, clear pain |
| `hiring sdrs` | trigger-specific |
| `{{company}} outbound` | segment token beyond first name |
| `post-funding outbound` | timing trigger |
| `owner routing` | mechanism-level clarity |

## Audit vignette

Subjects submitted:

1. `FREE Demo This Week!!!`
2. `quick thought`
3. `{{company}} reply lag`

Expected:

1. **kill** — spam + !!! + CAPS energy  
2. **rewrite** — vague curiosity, no trigger  
3. **keep** — lowercase, specific, front-loaded  

Recommended set:

1. `{{company}} reply lag`
2. `hiring sdrs`
3. `owner routing`

Measurement note: pick the winner on **reply rate** after the full reply window.
Use ≥500 delivered recipients/variant only as a rough exploratory floor, not
500 actual replies; use a power calculation for consequential decisions.
