# Omnichannel channel rubric

Score each lever 1–5 (5 = strong). No industry % benchmarks.

| Lever | 5 looks like | 1 looks like |
| --- | --- | --- |
| Channel fit | Email carries narrative/CTA; social earns attention or soft bumps | Same long pitch pasted into every channel |
| One job per touch | Each step has one clear job | Steps stack connect + pitch + book-meeting |
| Familiarity before ask | Cold social ask is light; heavier ask after signal | Instant hard CTA on first social touch |
| Handoff clarity | Reply/accept stops automation; owner named | Parallel sequences keep firing after engagement |
| Volume safety | Caps and spacing stated; social limits respected | Max parallel touches with no caps |
| Offer coherence | Same value prop; proof density matches channel | Conflicting offers or bait-and-switch by channel |
| Exit / breakup | Explicit last step | Endless bumps |

**Weakest lever** drives the rewrite focus.
