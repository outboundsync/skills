# Value-equation rubric

Unattributed operating model for scoring cold-outreach offers.

## Formula

**Value = (Dream Outcome × Perceived Likelihood) / (Time Delay × Effort & Sacrifice)**

The formula uses **raw costs**: lower Time Delay and lower Effort & Sacrifice
increase value. Do not plug the positive audit scores below into its
denominator.

For an intuitive audit scorecard, convert the denominator factors to their
positive inverses:

- **Speed to Value** — `5 = fast`, `1 = slow`
- **Ease** — `5 = low effort`, `1 = high effort`

Report the four positive 1–5 scores. Do not calculate a floating-point value
score; the model is for diagnosing the weakest lever, not manufacturing
precision.

## Scoring grid

### Dream Outcome (1–5)

| Score | Criteria |
| --- | --- |
| 5 | Specific metric + timeframe + mechanism (e.g. “cut reply lag 40% in 14 days by fixing X”) |
| 4 | Metric + timeframe, mechanism fuzzy |
| 3 | Clear directional outcome, no number |
| 2 | Vague benefit (“grow pipeline”, “save time”) |
| 1 | Feature dump or product pitch with no outcome |

### Perceived Likelihood (1–5)

| Score | Criteria |
| --- | --- |
| 5 | One tight peer proof (same role/ICP, concrete result) + low-key risk-reversal |
| 4 | Credible peer proof without risk-reversal |
| 3 | Soft social proof (category claim) or mechanism that makes success feel plausible |
| 2 | Generic “teams like yours” with no specifics |
| 1 | No proof; hype words; fabricated urgency |

**Default failure mode:** low Perceived Likelihood. If Dream Outcome is strong but Likelihood ≤ 2, name Likelihood as the failing lever.

### Speed to Value (1–5) — inverse of Time Delay

| Score | Criteria |
| --- | --- |
| 5 | Value in days (audit, checklist, diagnosis, sample) before any call |
| 4 | Clear path to first win in ≤ 1–2 weeks |
| 3 | Value framed in weeks; call still required to start |
| 2 | Value requires multi-week project or long sales cycle to feel |
| 1 | “Book a demo” as the only next step; no compressed time-to-value |

### Ease (1–5) — inverse of Effort & Sacrifice

| Score | Criteria |
| --- | --- |
| 5 | Soft interest reply only; no calendar, no prep, no data dump |
| 4 | Optional resource accept (one-click / one-reply) |
| 3 | Short async ask (answer 1–2 questions by email) |
| 2 | 15-min call framed as a give (still higher effort) |
| 1 | 30-min demo, form fills, stacked asks, or homework on touch 1 |

**Default failure mode:** low Ease (score ≤ 2). Soft CTAs raise this lever.

## Naming the failing lever

1. Score all four.
2. If Perceived Likelihood ≤ 2 and Dream Outcome ≥ 3 → fail lever = **Perceived Likelihood**.
3. Else if Ease ≤ 2 → fail lever = **Ease**.
4. Else if Speed to Value ≤ 2 → fail lever = **Speed to Value**.
5. Else if Dream Outcome ≤ 2 → fail lever = **Dream Outcome**.
6. Else pick the lowest score; if tie, prefer Likelihood then Ease.

## Overall band

| Band | Rule of thumb |
| --- | --- |
| weak | Any lever ≤ 2 |
| fair | All levers ≥ 3, but the strong rule is not met |
| strong | All four levers ≥ 4 |

## Fixes by lever

| Weak lever | Fix |
| --- | --- |
| Dream Outcome | Quantify metric + timeframe + mechanism; cut features |
| Perceived Likelihood | Add one peer proof; add low-key risk-reversal; remove hype |
| Speed to Value | Offer a give first (audit, template, diagnosis); compress path to first win |
| Ease | Drop to soft interest CTA; one ask; < ~15 words; standalone line |

## Audit test (independent of scores)

Every offer must still answer:

1. **Why you** — why this sender/product is relevant to this recipient
2. **Why now** — trigger, timing, cost of waiting
3. **What do I get by replying** — the micro-commitment payoff, not the full product
