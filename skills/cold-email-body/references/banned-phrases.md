# Banned phrases (cold email body)

If any item appears, Language category → **0** and Findings get an ✗ line. Prefer deletion over clever paraphrase that keeps the same empty politeness.

## Openers (hard ban)

| Phrase | Note |
| --- | --- |
| I hope this finds you well | ≈ **−47% replies** (directional) |
| I hope you're doing well | same class |
| Hope all is well | same class |
| Trust you are well | same class |
| Congrats on … (empty flattery) | congrats-opener without operational signal |

- cutting-edge

- alignment / circle the wagons

## Follow-up emptiness

- just checking in
- just bumping this
- circling back
- circle back
- touching base
- following up to follow up
- any update here? (alone, no new value)

## Meeting pressure (touch 1)

- quick call
- hop on a call
- grab time
- pencil in
- calendar link / “here’s my calendar”
- book a demo
- schedule a meeting
- 15/30 minutes of your time (as the only ask without prior engagement — prefer soft interest first)

## Multi-ask / gimmick CTAs

- reply YES
- reply YES if interested, NO if not (gimmick; still a hard pattern)
- stacked: reply + book + download

## Allowed replacements

| Banned energy | Better |
| --- | --- |
| Hope this finds you well | Start on the signal |
| Just checking in | New proof, new angle, or breakup |
| Quick call? | Soft interest / resource ask |
| Congrats on the funding! | `Saw the {{round}} — usually outbound volume jumps before reply systems catch up.` |

## Detection tips

- Case-insensitive scan
- Flag partials: “checking in”, “bumping this”, “circling back”
- “Congratulations” is fine only when paired with a **verifiable operational implication**, not flattery alone
