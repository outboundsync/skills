# Body scoring rubric (/100)

## Point allocation

| Category | Points | What earns full marks |
| --- | --- | --- |
| Length / readability | 20 | 50–100 words, 3–4 sentences, ~3rd–5th grade, one phone screen |
| Personalization | 20 | Signal-led + passes removal test |
| Structure | 20 | Signal → Problem+Solution → Proof → soft CTA (or clean PAS/BAB) |
| CTA | 15 | Exactly one soft interest ask; standalone; no calendar/demo |
| Hygiene | 15 | Plain text; no links/images/attachments; tracking off guidance |
| Language | 10 | You/your voice; zero banned phrases |

**Bands:** fail <50 · weak 50–69 · solid 70–84 · strong 85–100.

## Length / readability (20)

| Score | Rule |
| --- | --- |
| 20 | 50–100 words, 3–4 sentences, short words, scannable on one phone screen |
| 12 | 40–49 or 101–120 words, still mostly clear |
| 6 | 5+ sentences or dense jargon |
| 0 | Wall of text, feature dump, or <30 words with no substance |

## Personalization (20)

| Score | Rule |
| --- | --- |
| 20 | Verifiable signal (post, hire, stack, metric, trigger) woven so removing it collapses relevance |
| 12 | Specific but decorative (passes removal test → still works as generic) |
| 6 | Name/title/`{{company}}` only |
| 0 | Fully generic or fake-personalized |

**Removal test:** Delete the personalized line. If the email still stands as a coherent blast, personalization was decorative → cap this category at 12.

Directional: signal-led ≈ **11% reply** vs generic ≈ **2%** (~5×).

## Structure (20)

| Score | Rule |
| --- | --- |
| 20 | Clear Signal → Problem+Solution → Proof → soft CTA (or intact PAS/BAB) |
| 12 | Order slightly off but all pieces present |
| 6 | Missing proof or signal |
| 0 | Pitch-first / feature dump / no CTA |

## CTA (15)

| Score | Rule |
| --- | --- |
| 15 | One soft interest CTA; single-ask (~9.1% vs multi ~2.4% directional) |
| 8 | Soft but buried or slightly long |
| 4 | Hard ask (demo/calendar) alone |
| 0 | Stacked CTAs, “reply YES”, or no ask |

## Hygiene (15)

| Score | Rule |
| --- | --- |
| 15 | Plain text; zero links/images/attachments on touch 1; advise open pixel OFF + link tracking off (+2–10 pts placement) |
| 8 | One mild signature link only (still flag for touch 1) |
| 0 | Images, attachments, tracked links, or pixel-on cold send |

## Language (10)

| Score | Rule |
| --- | --- |
| 10 | You/your dominant; no banned phrases |
| 5 | Mild we/our; no banned |
| 0 | Banned phrase present (see banned-phrases.md) |

## Automatic fail flags (annotate even if points remain)

- “I hope this finds you well” (−47% replies directional)
- Calendar link on touch 1
- Congrats-opener flattery with no operational signal
- Multi-ask CTA block
